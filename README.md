# ➕ Add Two Numbers

A beginner JavaScript exercise that reads two numeric inputs, adds them, and displays the result on the page.

## ✨ What it does

1. Accepts two numbers through input fields.
2. Reads their values from the page.
3. Converts the values to numbers.
4. Calculates the sum.
5. Prints both inputs and the result in the output area.

## 🛠️ Built with

- HTML5
- JavaScript

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t8-1.git
cd t8-1
~~~

Open `index.html` in a browser, enter two numbers, and select **Add**.

## 📁 Files

- `index.html`: number inputs and result area.
- `script.js`: addition function.
